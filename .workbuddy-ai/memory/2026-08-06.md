# 2026-08-06

## Student Dashboard — Newest Exams Section

Added a "Newest Exams" component to the student dashboard home page
(`app/[locale]/student/page.tsx`).

### What was built

1. **`src/services/student/exam.service.ts`** — new server-side service
   - `getLatestStudentExams(limit = 4)` calls `GET /v1/quiz?page=1`
   - Normalizes the response (handles both flat array and `{ data: [] }`
     wrappers) and returns a typed `LatestExamSummary[]`
   - Derives a `status` (`available` / `upcoming` / `expired`) by comparing
     `start_time` / `end_time` against `Date.now()`
   - Filters out already-expired exams
   - Sorts by `start_time` desc with `created_at` fallback, then slices
     to the requested limit

2. **`src/components/student/home/NewestExams.tsx`** — new section card
   - Matches the visual style of `GetStudentNotes` / `LatestPostsSection`
     (same card pattern: icon chip on the left, title + meta in the middle,
     action on the right)
   - Shows exam title, type (`exam` / `homework`), duration, start time,
     and an availability badge
   - Available exams render a `Start Exam` button linking to
     `buildStudentStartExamHref(locale, id, course_id)` — the same path
     used elsewhere in `StudentExamsHub`
   - Empty state with localized "no exams" message
   - "View All" link points to `/${locale}/student/exams`

3. **i18n** — added `students.home.exams` keys in both `messages/ar.json`
   and `messages/en.json` (`title`, `viewAll`, `empty`, `fallbackTitle`,
   `examType`, `homeworkType`, `startExam`, `availableBadge`,
   `upcomingBadge`, `durationMinutes`, `questionsLabel`, `courseFallback`).

4. **Wired into `app/[locale]/student/page.tsx`** — added the new import,
   fetched `getLatestStudentExams(4)`, and placed the section after
   `LatestPostsSection` and before the 2-column grid (live classes + notes).

### Notes / Gotchas

- `QuizAttributes.course_id` is typed as `number | undefined`, so the
  `typeof === "string"` branch in `pickFirstCourseId` narrowed to `never`.
  Fixed by widening `courseIdRaw: unknown` first.
- Pre-existing TS build errors exist in
  `app/(doctor)/doctor/electronic-library/add/page.tsx` (`is_preview` not
  on `CreateLibraryRequest`) — unrelated to this task; do not attempt
  the full `next build`, use `tsc --noEmit` for incremental checks.
- The page pre-existing lint warnings (unused imports
  `QuickActivationCard`, `getCourseById`, `getStudentNotifications`) are
  legacy and not part of this change.
